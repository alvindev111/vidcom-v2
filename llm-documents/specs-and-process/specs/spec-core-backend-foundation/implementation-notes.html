Phiên 2026-08-01 — Write authority và recovery Phase G

Design đã đồng bộ
Quyết định
Mọi mutation ghi intent trước filesystem, giữ lease workspace và mutex theo project. Reconciliation so hash thật với from/to hash; nhánh mơ hồ chỉ orphan + audit, không ghi đè dữ liệu người dùng, đồng thời trả journal ID để startup/doctor surface.
Design drift
Bổ sung previous_content và byte size vào pending journal vì recovery sau rename cần dựng revision_blob mà file cũ không còn. Bootstrap được sửa thành transaction A đăng ký/seed/pending, atomic write, rồi transaction B settle; không giữ transaction SQLite xuyên filesystem I/O.
Bằng chứng
22 test Phase G trọng tâm xanh. Năm crash-recovery case dùng child process và SIGKILL: sau journal, giữa write, sau rename, giữa commit transaction và third-party overwrite. Concurrency thật cho đúng một winner; lease peer bị từ chối, takeover sau TTL và daemon cũ nhận workspace_lease_lost.
Bất ngờ / cạm bẫy
SQLite blob trả Uint8Array, nên pending intent không thể giả định giữ kiểu string. Kill giữa commit phải để transaction chưa COMMIT; khi process chết, WAL rollback và startup recovery tạo đúng một revision/blob/event thay vì nhân đôi.

Phiên 2026-08-01 — Job infrastructure Phase L

Design đã đồng bộ
Quyết định
SQLite là nguồn trạng thái duy nhất. Claim dùng conditional update; scheduler giới hạn theo type và loại cặp project/type đang active khỏi truy vấn tiếp theo để không overlap cũng không chặn project khác. Cancel queued kết thúc ngay, cancel running được worker nhận ở safe point.
Design drift
Đã cập nhật §5.2/§5.9: Job nội bộ có input, project, hash, cancel và heartbeat nhưng route chỉ trả JobDto. Port thêm đọc cancellation, requeue stale và excluded active pair. Mô tả noop được sửa để kiểm huỷ thật sự ở đầu vòng, trước sleep.
Bằng chứng
7 integration test mới khóa canonical hash ba trường hợp, atomic claim, monotonic progress, concurrency 2 không overlap cùng cặp, cancel + cleanup, failure, đóng/mở lại DB rồi requeue/fail theo idempotent, và GET/cancel qua auth perimeter. Toàn suite 26 file/150 test xanh; typecheck, boundary, lint và build đều exit 0.
Bất ngờ / cạm bẫy
Kysely suy rộng CASE status thành string, không còn khớp union schema. Hai conditional update queued/running vừa giữ type-safe vừa xử lý race claim/cancel. Lệnh bun test gọi test runner Bun không hỗ trợ node:sqlite; CI đúng của repo là bun run test, tức Vitest trên Node, đã xanh.

Phiên 2026-08-01 — Event, watcher và cache Phase M

Design đã đồng bộ
Quyết định
Outbox SQLite là nguồn duy nhất cho resume SSE, giữ tối đa 24 giờ và 5000 dòng. Scheduler persist job trước khi append progress/done. Watcher nhích revision entity khi sửa ngoài, invalidate cache theo event và không tự phát lại write nội bộ.
Design drift
Đã cập nhật §4.3.3/§5.11: WriteAuthority báo hash vừa commit qua observer composition-root; watcher consume hash, dedupe notification cùng nội dung và bỏ qua sibling temp của atomic writer. ProjectReadDependencies nhận cache optional cho test, production luôn dùng instance chung.
Bằng chứng
6 test mới phủ reopen DB + retention gap, LRU/reject, fs.watch thật + debounce, external revision conflict, one-event mutation, job poll/SSE cùng trạng thái, resync, heartbeat và chunk event đi qua Next catch-all không buffer. Tổng 28 file/156 test xanh; typecheck, boundary, lint và build exit 0.
Bất ngờ / cạm bẫy
Một atomic write tạo event cho cả temp file và target; chỉ so target hash vẫn sinh event thừa. Test one-logical-event bắt được lỗi này. Watcher nay bỏ qua đúng mẫu temp và nhớ hash cuối để nhiều notification của cùng rename chỉ xử lý một lần.

Phiên 2026-08-01 — Sửa finding hậu review P1/P2

Security regression đã khóa
Quyết định
